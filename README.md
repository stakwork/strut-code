# strut-code

The `stadeum/code` package for [strut](https://github.com/stakwork/strut): the
repositories a box works on, the workspaces they are grouped in, and the Code
app where they are set up. It names no forge.

Nothing is published yet. The package will sit at this repository's root, and
a box will follow its `stable` branch:

```text
git+https://github.com/stakwork/strut-code@stable
```
