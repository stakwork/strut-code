The code this box works on, as pages: the way in for a person and for a
model. This page stays as it is. The pages under it change.

- **A page for each workspace that has been baked,** `<workspace>
  workspace` (`hive workspace`). The `stadeum/pods` package writes it at
  the bake: a diagram of the workspace's systems, each arrow a real
  connection labelled with the setting that points it, then the system
  in words, then how to run it. Start there to see how a workspace's
  repositories fit together. A workspace never baked has none.
- **Later, a page for each repository,** here and under each of its
  workspaces' pages, and **a page for each feature** under its
  repository's. The dream keeps them in step with what is merged.

The repositories themselves, and the workspaces they are grouped in, are
on the `Repositories` page and in the Code app.
